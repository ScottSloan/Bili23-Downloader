# 媒体检查使用说明

独立检查工具用于读取已下载文件的实际音视频规格，无需启动 GUI 或读取登录凭据。它执行容器和轨道检查，不执行整片解码，也不改变原文件及任务数据库。

## 运行方式

需要 Python 3.11 或以上，以及可执行的 ffprobe。ffprobe 可以与项目 `bundle/ffmpeg` 放在同一目录、位于系统 PATH，或通过参数指定。工具不会自动下载外部程序。

```sh
.venv/bin/python scripts/verify_media.py '/path/to/video.mp4' --expect-video --expect-audio
.venv/bin/python scripts/verify_media.py '/path/to/audio.m4a' --expect-audio
.venv/bin/python scripts/verify_media.py '/path/to/video.mp4' --ffprobe '/path/to/ffprobe' --expected-duration 2700
```

时长单位为秒。偏差超过两秒与预期时长的百分之一两者中的较大值时产生警告。该容差是初始策略，后续 GUI 接入时需结合实际内容继续验证。

## 输出和退出码

输出 JSON，包含 `status`、`reason`、`duration`、`format_name`、`streams`、`warnings`。轨道包含实际编码、分辨率、采样率、声道数和可用的码率；未知值为 `null`，不会使用总码率补充音频码率。内嵌封面不计作可播放视频轨道。

| 状态 | 退出码 | 含义 |
| --- | --- | --- |
| `verified` | 0 | 快速结构检查通过，不代表完整解码通过 |
| `warning` | 0 | 有时长差异，需结合来源确认 |
| `failed` | 1 | 文件不存在、无法探测或缺少所要求的轨道 |
| `unverified` | 2 | 工具缺失、不可执行、超时、取消或超过输出限制 |

默认超时 15 秒。模块调用方可传入取消事件；超时或取消后终止并回收子进程。输出保存在临时文件中，轮询检查 1 MiB 阈值后停止进程，避免持续输出；轮询间隔内可能短暂超过阈值。

## 实现进度

已完成独立探测模块 `src/util/media_probe.py`、命令行入口及故障路径测试。模块可独立导入，不初始化 Qt 或用户配置。

已接入已完成任务右键菜单中的 Inspect media 入口。窗口展示实际规格，点击 Inspect 在后台重新检查；关闭窗口会请求取消。结果保存到已有任务 JSON 的 File.verification 字段，旧记录默认空结果，无需修改表结构。更新仅作用于仍存在的已完成任务，不会恢复已删除记录。

尚未接入每次下载后的自动检查、请求规格差异展示及深度解码入口。当前按实际输出文件检查；未合并的音视频分别列出。主计划阶段一仍为进行中。

本机已通过 Homebrew 官方源和现有本地代理安装 FFmpeg 与 ffprobe 9.0.2，未修改全局源或代理配置。对《中国通史》第一集运行真实检查，返回 `verified`：时长 2700.0095 秒，H.264 1920×1080，AAC 48 kHz 双声道，音频码率 320003 bit/s，无警告。工具缺失的降级路径也已验证。

新增测试 6 项通过。首次全量回归为 771 项通过、3 项失败；原始提交上复测同样复现两个命名编辑器布局失败和一个负时间戳时区断言失败。它们未在本次修改中处理。

GUI 接入新增 4 项测试，覆盖旧记录往返、结果保存与删除、窗口取消及后台检查到结果保存的联动。联动测试替换媒体探测，真实 ffprobe 已由 CLI 单独验证。GUI 接入后全量回归 776 项通过，仍为原有 3 项失败；之后新增的联动测试单独通过。跨平台视觉和交互验收尚未完成。
